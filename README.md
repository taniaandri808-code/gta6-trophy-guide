Offline GTA VI PS5 trophy guide + progress tracker built for the make.fun bounty gta6-trophy-guide-01:
all 55 official trophies with name, description, grade and a per-trophy guide in our own words with
sources cited; checklist saved in the browser with export/import; filters; a spoiler setting for
story trophies; a roadmap to the platinum; missable trophies flagged. Static files, works offline
in desktop Chrome. No Rockstar logo or official artwork — original visual identity.

## Run it

```sh
npx serve .    # or open index.html directly in desktop Chrome
```
